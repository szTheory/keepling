<objective>
Expose the reads MCP-01 names — Inbox, Today, Upcoming, Completed, project, task, and search — as
MCP resources over the transport plan 05-01 proved, and decide the phase's MCP surface coverage
explicitly rather than letting a representative host discover the holes.

Purpose: MCP-01 is a read requirement with a least-privilege qualifier. The risk in a protocol
adapter is not a missing feature but a *partially* implemented protocol that a host probes and
finds holes in. This plan makes the coverage a written decision.

Output: a bounded, redacted-by-construction read surface, and `docs/architecture/MCP-SURFACE.md`
recording what is implemented and what is deliberately not.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP host → `resources/read` | Untrusted resource URI and cursor cross here |
| Resource handler → application query | The authoritative `tasks.read` gate |
| Domain row → resource payload | Redaction boundary: what a model is allowed to see |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-18 | Information Disclosure | `MCP.Redaction` | critical | mitigate | Explicit field-by-field projection with an exact key-set test; a field added to a domain row cannot reach a model until the projection names it |
| T-05-19 | Elevation of Privilege | read scope enforcement | critical | mitigate | `tasks.read` checked at the adapter and independently re-checked at the application boundary, with a test that bypasses the first and asserts the second still refuses |
| T-05-20 | Information Disclosure | `keepling://tasks/{task_id}` | high | mitigate | A foreign or unknown identity returns one stable not-found error, so identity existence is not probeable |
| T-05-21 | Denial of Service | `resources/read` paging | medium | mitigate | Hard maximum page size clamped; the `:mcp` pipeline's rate limiter applies; no unbounded enumeration path exists |
| T-05-22 | Tampering | `MCP.Dispatch` closed method list | medium | mitigate | `surface_test.exs` binds the closed list to `MCP-SURFACE.md`, so an undeclared method cannot be added silently |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager install occurs in this plan. Any future install proposal requires the package-legitimacy gate and a blocking human checkpoint first |
</threat_model>
