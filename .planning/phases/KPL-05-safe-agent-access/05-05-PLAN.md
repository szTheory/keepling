<objective>
Give the agent a small, closed, contract-generated write surface: capture, update, complete,
reopen, plus the preview and commit pair plan 05-07 fills in. Deliberately not a mirror of the
twelve command endpoints — a task-shaped tool surface is what MCP hosts use well, and every extra
tool is extra authorization surface a language model can reach (D-11).

Purpose: MCP-02's whole content is "through closed schemas and stable, model-correctable errors".
A schema that drifts from the contract, or an error string that varies between runs, defeats both
halves — a model cannot learn to correct against a moving target, and a varying string cannot be
asserted in a deterministic lane.

Output: generated closed tool schemas gated by CI, four working write tools, and a closed error
vocabulary with golden vectors.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP host → `tools/call` | Untrusted tool arguments cross here |
| Generated schema → adapter decoder | Contract drift boundary; a disagreement is a CI failure |
| Adapter → `Commands.dispatch/3` | The invariant boundary that must not be relaxed for an agent |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-23 | Tampering | tool input validation | critical | mitigate | `additionalProperties: false` in the generated schema plus the exact-key Elixir decoder; both run, and a disagreement between them fails a test |
| T-05-24 | Tampering | replayed tool call | high | mitigate | Client-generated mutation identity plus expected revision, unrelaxed for agents; replay returns the stored result and advances no revision |
| T-05-25 | Elevation of Privilege | tool surface size | high | mitigate | Six tools total, not a mirror of the twelve command endpoints; a tool absent from `tools/list` has no dispatch path |
| T-05-26 | Information Disclosure | error rendering | medium | mitigate | Fixed literal strings only, no interpolation, no stack traces; internal failures collapse to one member |
| T-05-27 | Repudiation | contract drift | medium | mitigate | `pnpm contracts:check` regenerates into scratch and diffs, so a contract change that is not regenerated fails CI rather than surfacing at runtime in front of a model |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new package is installed: the generator is plain Node using the existing `openapi-typescript` devDependency chain. If a schema-resolution library is later proposed, the package-legitimacy gate and a blocking human checkpoint apply first |
</threat_model>
