## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Test-only state injection seam -> shipped app | A reachable injection path in a release build would let arbitrary presentation state be forced. |
| Task content -> layout and system chrome | Adversarially long or non-Latin content is untrusted input to the layout engine. |
| Presentation state -> the person's trust decision | A state that renders as healthy when it is not is the highest-severity failure IOS-04 guards. |
