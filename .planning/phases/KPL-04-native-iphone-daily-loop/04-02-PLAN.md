## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App process -> app-container SQLite durable unit (db, -wal, -shm) | All local intent lives here; corruption or partial write is direct user data loss. |
| Prior Keepling build -> current build (same store file) | A database written by a different schema version crosses a version boundary at open. |
| Test fault seam -> shipped app target | A test-only failure injector must never be compiled into the app. |

## STRIDE Threat Register

| T-04-02-01 | Tampering | Migration text vs stored checksum | high | mitigate | Task 1's app-owned ledger halts on checksum drift and never repairs or resets the store (ASVS V8). |
| T-04-02-02 | Denial of Service | Store opened by an older build after a newer one migrated it | high | mitigate | Task 1's ahead-of-ledger refusal declines to open rather than downgrading the schema. |
