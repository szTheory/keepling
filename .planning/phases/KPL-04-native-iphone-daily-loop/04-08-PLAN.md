<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Outbox row -> network -> server | Command bytes leave the device; a retry that is not byte-identical is a different command. |
| Two concurrent sync passes -> one outbox row | Double transmission is the duplication failure IOS-02 forbids. |
| OS background scheduler -> app process | An untrusted, non-deterministic trigger that must never carry correctness. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-08-01 | Repudiation | Retry regenerating command bytes | high | mitigate | The retry path reads stored `immutable_commands` bytes; a test mutates the in-memory value and requires the retried bytes unchanged. |
| T-04-08-02 | Elevation of Privilege | Two passes double-pushing one row | high | mitigate | The `queued` -> `in_flight` claim happens inside the selecting transaction; a concurrency test requires exactly one push. |
| T-04-08-03 | Repudiation | Unheard answer recorded as queued or rejected | high | mitigate | The three-state machine sends a thrown transport error to `uncertain`; the recorded prohibition forbids settling an unheard answer. |
| T-04-08-04 | Elevation of Privilege | Pass running under a fenced namespace | high | mitigate | The fence refuses the pass before any request is built, asserted with a transport stub that fails if called. |
| T-04-08-05 | Denial of Service | Unbounded pull or push under a large backlog | medium | mitigate | Bounds 50 and 25 read from the reducer's named constants; a backlog test proves the pass terminates. |
| T-04-08-06 | Information Disclosure | Background task metadata carrying task content | medium | mitigate | The background handler passes no user content to the OS; Plan 04-15's privacy scan covers the diagnostic surface it writes. |
| T-04-08-07 | Denial of Service | Background expiration leaving partial state | medium | mitigate | The expiration test asserts every outbox row is in a legal state and no transaction is partially applied. |
</threat_model>
