<objective>
Give the iPhone a wire client that tells the difference between a server that did not answer and a server that answered no — and prove the generated decoder can actually read what the server sends.

Purpose: Phase 3's O-30/O-38 defect class was a decided command retried forever because an answered refusal was indistinguishable from an unreachable server. That distinction lives in exactly one function, and it must exist in Swift before the orchestrator in Plan 04-08 starts driving pushes.

Output: a URLSession-backed adapter over the committed generated client, a closed refusal classifier, hand-written wire mappers, and a decode round-trip suite over every payload in the golden vectors.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Keepling HTTP API -> generated Swift decoder | Untrusted server bytes become typed Swift values; a decode ambiguity is a tampering surface. |
| Generated DTO -> client model -> persistence | The four-deliberate-representations boundary; a generated type reaching persistence couples the store to the wire. |
| URLSession failure -> outbox state | Misclassifying an unheard answer as a settled one loses or duplicates accepted intent. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05-01 | Tampering | oneOf decode picking a structurally overlapping sibling | high | mitigate | Discriminated decoding asserted per variant in Task 1; malformed bodies fail rather than falling through (ASVS V5). |
| T-04-05-02 | Tampering | Nullable field decode never exercised with a real null | high | mitigate | Task 1 enumerates nullable fields from the contract and requires an explicit-null decode for each, synthesizing a fixture where the vectors do not cover it. |
| T-04-05-03 | Repudiation | Unheard answer settled as a decided outcome | high | mitigate | Task 2's single classification boundary: only a thrown URLSession error yields unreachable; the recorded prohibition forbids settling an unheard answer. |
| T-04-05-04 | Information Disclosure | Bearer credentials over plaintext HTTP | high | mitigate | Task 2's HTTPS-only guard rejects an http base URL outside loopback at adapter construction (ASVS V9). |
| T-04-05-05 | Tampering | Server answer overwriting a person's unsent edit | high | mitigate | A 409 settlement applies only the affected fields the server returned and never replays the canonical shadow; asserted by test. |
| T-04-05-06 | Elevation of Privilege | 401 collapsed into a per-mutation rejection | high | mitigate | A 401 is a distinct tagged state that no acknowledgement outcome can represent, asserted by test (ASVS V2/V3). |
| T-04-05-07 | Denial of Service | Unbounded retry of a decided refusal | medium | mitigate | The closed settleable-refusal set terminalizes decided outcomes; anything unlisted throws rather than looping. |
