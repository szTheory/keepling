<objective>
Make a bad day on the phone reconstructable without making the log a copy of the person's task list.

Purpose: D-23 sets both halves of this at once — diagnostics must be rich enough to reconstruct a synchronization failure over USB, and must carry no task content, credential, cursor, or fingerprint. A log that satisfies only the first half is a privacy failure; one that satisfies only the second is useless at exactly the moment it matters.

Output: a closed diagnostic event vocabulary, a coverage test proving every meaningful transition emits one, an export bundle for the Inspect and Export recovery actions, and a leak scan asserted against real values.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App process -> on-device diagnostic log -> USB retrieval | The log leaves the device to a machine the person plugs it into. |
| App process -> system unified log | A surface outside the app's storage that other tooling can read. |
| Accessibility announcements -> spoken output | Content here is audible to anyone nearby. |
