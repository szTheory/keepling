<objective>
Buy Shortcuts, Siri, the Action Button, and Spotlight actions for roughly two files — without a second process, a second store handle, or an App Group container.

Purpose: D-35 identifies this as the high-leverage capture move precisely because it adds reach without touching the storage architecture. The discipline that makes it safe is that the intent runs in the main process against the one store handle that already exists, which is also what keeps D-36's deferred extensions genuinely deferred rather than half-built.

Output: Capture and Complete intents declared in the main app target, an in-process store access seam, and tests that drive perform through the real resolution path.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Shortcuts / Siri / Spotlight -> app intent perform | An OS-mediated invocation path that bypasses the app's own UI, including while the app is not foregrounded. |
| Intent metadata -> system indexes and donated entities | Intent phrases, parameter summaries, and dialogs are surfaced by the OS outside the app's control. |
| Intent process -> store handle | A second store handle would reintroduce the multi-writer hazard D-07 and D-36 exist to avoid. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-12-01 | Elevation of Privilege | Intent writing under a fenced namespace | high | mitigate | The intent path takes the same fence check as every other write path, before any transaction opens. |
| T-04-12-02 | Information Disclosure | Credentials or identifiers in intent metadata or donated values | high | mitigate | `IntentPrivacyTests` scans every intent-surfaced string for the test's actual secret values (D-23, ASVS V8). |
| T-04-12-03 | Denial of Service | A second store handle from an intent invocation | high | mitigate | `IntentStoreAccess` exposes no path-taking initializer, so a second connection is structurally unreachable (D-07/D-37). |
| T-04-12-04 | Repudiation | An intent stranding a durable capture draft | medium | mitigate | The draft lives in the store, and a test performs an intent with a draft present and requires it to survive. |
| T-04-12-05 | Tampering | An intent bypassing command byte or fingerprint derivation | high | mitigate | The intent invokes the same `OutboundCommands` path; a test asserts byte-identical output against the sheet path. |
| T-04-12-06 | Spoofing | A non-functional affordance implying a deferred surface exists | medium | mitigate | A source scan fails on any widget, control, or extension declaration under `apps/ios/Sources`. |
| T-04-12-07 | Information Disclosure | Task content indexed by Spotlight through intent donation | low | accept | Phase 4 ships no Spotlight-index surface (D-36); only intent actions are exposed, and the privacy scan covers their strings. |
</threat_model>
