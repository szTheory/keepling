<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Task content -> rendered view | Task titles and notes are untrusted user text rendered into UI and accessible names. |
| Presentation layer -> store, transport, credentials | The D-45 boundary; a view holding a store handle can bypass every invariant beneath it. |
| Gesture -> irreversible command | A cheap gesture bound to a recoverable-but-consequential action is a data-loss surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-09-01 | Tampering | Task title or notes interpreted as markup | high | mitigate | All task-owned text renders as plain text in the Body role; a markup-character title is asserted to render literally (ASVS V5). |
| T-04-09-02 | Elevation of Privilege | A view reaching the store, transport, or credentials directly | high | mitigate | `WorkspaceFacade` is the only presentation input and a derived-name source scan asserts zero occurrences of storage, transport, or credential types under `Sources/Keepling`. |
| T-04-09-03 | Repudiation | Trash reachable by an accidental swipe | high | mitigate | Trash is bound only to the context menu and the detail view; a source scan asserts no swipe action references it. |
| T-04-09-04 | Repudiation | A nonempty capture draft silently discarded | high | mitigate | The draft is durable in the store rather than in view state and is removed only by a confirmed `Discard Draft`. |
| T-04-09-05 | Information Disclosure | Task content leaking into system chrome or accessible names beyond its own row | medium | mitigate | Accessible names are action-and-object scoped to the affected task; screen titles never carry quoted task content, asserted by the accessibility tests in Plan 04-13. |
| T-04-09-06 | Tampering | A local conflict merge overwriting server truth | high | mitigate | Resolution sends a fresh semantic command with a fresh mutation identity against current server truth; the client performs no merge. |
| T-04-09-07 | Denial of Service | Very large task lists degrading the list | low | accept | Native `List` virtualization is relied on; the overflow and long-text behavior is verified by the Plan 04-14 snapshot matrix rather than asserted here. |
</threat_model>
