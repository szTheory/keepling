<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Navigation trigger → routed application | User intent must open the real destination without spoofed or duplicate state. |
| Modal drawer → background document | Focus, pointer access, and route state cross an overlay boundary. |
| Server task data → responsive regions | Untrusted long content must reflow without hiding controls or creating overflow-based denial. |

## STRIDE Threat Register — OWASP ASVS Level 1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-KPL01-25-01 | Spoofing | Narrow navigation drawer | medium | mitigate | Semantic links, current-page state, inert background, focus entry/return, and route assertions. |
| T-KPL01-25-02 | Denial of service | Workspace layout and long content | medium | mitigate | Contract widths, reflow, independent scroll, and zero-overflow checks at boundary widths. |
| T-KPL01-25-03 | Tampering | Canonical task route composition | medium | mitigate | One TaskEditor instance keyed by canonical route and preserved authentication scope. |
| T-KPL01-25-SC | Tampering | Dependency supply chain | low | accept | Drawer uses the already-installed Base UI package; no install occurs. |
</threat_model>
