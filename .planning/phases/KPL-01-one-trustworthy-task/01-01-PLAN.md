## Trust Boundaries

| Boundary | Description |
|---|---|
| browser → Phoenix | Untrusted credentials, CSRF token, command bytes, IDs, and task text cross into the server. |
| Phoenix → application/domain | Transport DTOs and authenticated scope map into closed semantic values. |
| application → PostgreSQL | Concurrent commands contend for account-scoped receipt and task invariants. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-KPL01-01 | Spoofing | setup/login/session | high | mitigate | Single-use hash-stored setup; Argon2id login; session+CSRF rotation; Secure HttpOnly host-only Lax cookie; expiry/revocation tests. |
| T-KPL01-02 | Tampering | JSON capture route | high | mitigate | CSRF plus origin/host validation, strict closed schema, server-derived account/principal, no raw patch or controller Ecto access. |
| T-KPL01-03 | Tampering | mutation receipt transaction | high | mitigate | Account-scoped unique key, semantic fingerprint, stored terminal envelope, real concurrent replay tests. |
| T-KPL01-04 | Elevation | task/receipt lookup | high | mitigate | Account predicate from session on every task, receipt, and activity query; cross-account tamper tests. |
| T-KPL01-05 | Information disclosure | telemetry/errors | high | mitigate | Allow-listed diagnostics and negative tests excluding task content, credentials, raw tokens, and arbitrary IDs. |
| T-KPL01-SC | Tampering | npm/Hex installs | high | mitigate | Install only audited packages here; Plan 01-02 blocks before every research-flagged package. |
