fallback is correct and expected (#683) — do NOT force worktree dispatch, and do NOT create

that to the sentinel as a side effect. If you dispatch without re-arming, the isolation guard
hook **refuses the Agent() call**. Before each dispatch run:


property of the current repo state, not a project preference.
