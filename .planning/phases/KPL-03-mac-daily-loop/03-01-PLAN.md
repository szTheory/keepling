<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Renderer → preload/main | Untrusted renderer input crosses into privileged Electron and local storage. |
| Worker SQLite → local success | Partial or forged persistence state must not earn user-visible durability. |
| Packaged executable → evidence | Development bytes or a rebuilt artifact must not masquerade as tested installed bytes. |

## STRIDE Threat Register — ASVS Level 1
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-KPL03-01-01 | Elevation of privilege | preload bridge | high | mitigate | Context isolation, sandbox, strict named schemas on both sides, sender validation, no generic IPC. |
| T-KPL03-01-02 | Tampering | local acceptance transaction | high | mitigate | One worker writer, `BEGIN IMMEDIATE`, immutable bytes/fingerprint, post-COMMIT local_saved. |
| T-KPL03-01-03 | Repudiation | packaged evidence | high | mitigate | Package once, digest exact copied `.app`, assert executable path and embedded versions. |
| T-KPL03-01-04 | Denial of service | SQLite worker | medium | mitigate | Finite busy timeout, bounded values, forward migration failure shell seam, no main-thread DB calls. |
| T-KPL03-01-SC | Tampering | npm installs | high | mitigate | Blocking human provenance for SUS Electron/Zod pins; Forge packages are research-audited; fallback install remains blocked. |
</threat_model>
