## Trust Boundaries
| Boundary | Description |
|---|---|
| Global/native input → semantic commands | System events may be duplicated, composed, repeated, or owned by an editor. |
| Window state → app metadata | Private content and invalid geometry must not cross restoration/native title surfaces. |
| Quit/close → durable store | Lifecycle timing must not decide whether accepted intent exists. |
