# Project Research: Features

**Status:** imported synthesis of the 2026-08-28 exploratory study  
**Primary provenance:** `.planning/knowledge/snapshots/2026-08-28-current-worldview.md`, `2026-08-28-viability-and-open-source-operations.md`, `2026-08-28-mcp-agent-safety-and-evals.md`

## Table stakes for the personal-success milestone

- Near-instant capture, Inbox, Today, Upcoming, edit/clarify, complete/reopen, trash/restore, and undo.
- Explicit distinction between personal Today intent and deadlines.
- Complete keyboard workflow on Mac and deliberate native touch/accessibility on iPhone.
- Durable offline capture and mutation on Mac/iPhone across network loss, termination, relaunch, and retry.
- Trustworthy, visible synchronization with no silent loss, duplication, or overwrite.
- Neutral complete export and a tested recovery path.
- Calm, coherent, platform-native presentation with excellent empty/error/recovery states.

## Differentiators

- First-party semantic MCP/API access that uses the same domain rules as human actions.
- Least-privilege agent scopes, ambiguity without mutation, bound bulk previews, explicit confirmation, audit, and undo.
- Open-source/self-hosted portability with a genuinely turnkey, narrow operator contract.
- Restore verification rather than backup theater.
- High-quality native/offline clients rather than a web-only self-hosted task database.
- A product and brand designed for direct daily use, not a developer console wearing a consumer skin.

## Deliberate anti-features

- Collaboration, enterprise administration, chat, assignment, and broad work management.
- Embedded AI chat/model orchestration or a general autonomous planner.
- Arbitrary record patches, SQL, raw export, or URL fetching through MCP.
- Feature-list parity with broad competitors.
- Browser-offline work before the two primary durable clients prove the contract.
- A marketplace/plugin platform, attachments, or notification orchestration before the core loop is dependable.

## Complexity notes

Synchronization, recurrence, native lifecycle behavior, and recovery can dominate the project. The roadmap therefore gates each behind a narrow tracer and defers recurrence until core mutations survive dogfood.
